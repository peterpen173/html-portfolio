# מעקב לגו

כלי אישי לסימון כל קטלוג הלגו (כן/לא), לניהול רשימת המשאלות, ולמציאת המקום
הזול ביותר לרכוש סט חדש וסגור עם משלוח לישראל.

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `index.html` | הממשק: סימון כן/לא, רשימות, חיפוש מחירים, מחשבון מיסים |
| `scripts/build_catalog.py` | מוריד את קטלוג הלגו המלא ומזהה סטים חדשים |
| `scripts/notify_telegram.py` | התראת טלגרם על סטים חדשים (אופציונלי) |
| `data/` | נוצר אוטומטית: `catalog.json`, `new_sets.json` |
| `../.github/workflows/lego-catalog.yml` | הרצה יומית ב‑GitHub Actions |

## הפעלה ראשונה

1. **בניית הקטלוג.** ב‑GitHub: לשונית **Actions** ← **LEGO catalog sync** ←
   **Run workflow**. ההרצה מורידה את קובצי ה‑CSV הציבוריים של Rebrickable
   (בערך 23,000 סטים), בונה את `data/catalog.json` ודוחפת אותו לריפו.
   אין צורך במפתח API.

2. **הפעלת האתר.** ב‑**Settings ← Pages** בחרי `Deploy from a branch`,
   הענף הרלוונטי ותיקיית `/ (root)`. הכלי יהיה זמין בכתובת
   `https://<user>.github.io/<repo>/lego/`.

3. מכאן הסריקה רצה לבד כל יום ב‑05:10 UTC.

## שימוש

- **סימון** — כרטיס אחד בכל פעם עם תמונה, מספר סט, שנה, סדרה ומספר חלקים.
  מקלדת: `←` לא, `→` כן, `↑` כבר יש לי, `Z` ביטול. הסינון למעלה קובע את סדר התור.
- **חדשים** — סטים שנוספו לקטלוג מאז הסריקה הקודמת, לסימון מהיר.
- **האוסף שלי** — סטים שסימנת כקנויים, עם ספירה של כמה סטים יש לך, כמה חלקים
  הרכבת בסך הכל, ממוצע לסט, והסט הגדול ביותר — ופילוח חלקים לפי סדרה.
- **רשימת הכן** — כל סט עם כפתור **איפה הכי זול** שפותח חיפושים מוכנים
  ב‑BrickLink, BrickOwl, eBay, אמזון, זאפ, KSP, יד2 ופייסבוק מרקטפלייס,
  ומחשבון שמראה את העלות הסופית בשקלים כולל משלוח ומע״מ. אחרי רכישה, כפתור
  **קניתי** מעביר את הסט לאוסף.

## גיבוי הסימונים

הסימונים נשמרים ב‑`localStorage` של הדפדפן. **ייצאי קובץ גיבוי מדי פעם**
דרך לשונית ההגדרות.

לסנכרון בין מכשירים אפשר להגדיר Fine‑grained token עם הרשאת
`Contents: Read and write` על הריפו הזה בלבד; הסימונים נשמרים ב‑
`lego/data/decisions.json`. הטוקן נשמר בדפדפן שלך בלבד.

## התראות טלגרם (אופציונלי)

הוסיפי ב‑**Settings ← Secrets and variables ← Actions**:

- `TELEGRAM_BOT_TOKEN` — הטוקן מ‑[@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHAT_ID` — מזהה הצ׳אט שלך
- `SITE_URL` (משתנה, לא secret) — כתובת ה‑Pages, כדי שההודעה תכלול קישור לסימון

בלי ה‑secrets האלה השלב פשוט מדולג.

## מיסי יבוא

ברירת המחדל בכלי: פטור מלא עד 75$ לפי ערך הסחורה בלבד, ומעליו מע״מ 18% על
סחורה + משלוח. הסף חזר ל‑75$ ב‑2 ביוני 2026 אחרי שהכנסת ביטלה את ההעלאה
ל‑130$. מעל 500$ ייתכנו גם מכס ומס קנייה. אלה פרמטרים שניתנים לעריכה
בלשונית ההגדרות — כדאי לבדוק אותם מדי פעם מול
[מחשבון רשות המסים](https://www.gov.il/he/service/personal-import-tax-calculator).

## מגבלות ידועות

- **אין תמחור אוטומטי.** אין API אחד שמאגד מחירים מכל המקורות. הכלי מייצר
  חיפושים ממוקדים ומחשב את המיסים; ההשוואה עצמה ידנית.
- **יד2 ופייסבוק מרקטפלייס** אינם מספקים API, ו‑scraping שלהם נוגד את תנאי
  השימוש — לכן הם קישורים בלבד.
- **סטים ישנים** רבים זמינים רק בשוק האספנים, ולעיתים לא יימצאו כלל כחדשים
  וסגורים.
